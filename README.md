# Experience Semantic Protocol / TAOSS — Reference Implementation

Reference implementation (wire format, consent, conformance) of the
**Experience Semantic Protocol (ESP) V13** and its **Typed Approximately
Orthogonal Semantic Subspaces (TAOSS)**.

ESP transports typed, provenance-carrying, consent-bound semantic
representations (KNO, INT, EMO, CTX, SEN, TEM). It does **not** read minds,
transfer consciousness, or reliably detect emotions. See
`docs/MASTER_IMPLEMENTATION_PLAN.md` §4 and §59 (Claims Ladder).

The first L1 implementation is the
[Emotional Movie Search Engine](https://github.com/Vigilant-CRS/Experience-Semantic-Protocol_Emotional-Movie-Search-Engine).
