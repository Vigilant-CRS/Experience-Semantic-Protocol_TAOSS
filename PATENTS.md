# Patents

Statement of Vigilant e.K., 2026-09-30:

- Vigilant e.K. holds **no patents and no patent applications** related to the Experience
  Semantic Protocol (ESP) or TAOSS, and **does not intend to file any**.
- ESP is meant to be an open specification that anyone may implement.
- For the code in this repository, the patent license of AGPL-3.0-or-later (Section 11)
  applies as for any AGPL software.
- This statement is not a warranty that third parties hold no patents. See
  [docs/DISCLAIMER.md](docs/DISCLAIMER.md).

(An earlier draft of a patent non-assertion pledge, ADR-0006, is superseded by this statement.)
