# Patent Non-Assertion Pledge

Status: **DRAFT / PROPOSED** (ADR-0006). This pledge is **not yet in
force**. It becomes effective only after legal review (WP-084) and an
explicit release statement by Vigilant e.K.

## Intent

The Experience Semantic Protocol is meant to be an open standard that
anyone may implement. The code is protected by AGPL-3.0-or-later,
including the patent license in its Section 11. This pledge adds a
commitment for **independent implementations of the specification**,
which the AGPL alone does not cover.

## Draft pledge

Vigilant e.K. pledges not to assert any patent claim it owns or controls
that is necessarily infringed by implementing the Experience Semantic
Protocol specification (V13 and later versions published by Vigilant e.K.)
against any party, for making, using, selling, offering for sale,
importing or distributing a conformant implementation, royalty-free and
worldwide.

## Defensive termination

The pledge terminates for any party that initiates patent litigation
alleging that an implementation of the Experience Semantic Protocol
infringes a patent.

## Scope limits

- Only claims *necessarily* infringed by implementing the normative parts
  of the specification.
- Does not cover features beyond the specification.
- Does not grant trademark rights (see TRADEMARKS.md).
